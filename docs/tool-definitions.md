# Tool Definitions
* **Shopify Inventory Checker**: A mock tool that retrieves current product stock levels.
* **Buffer Scheduler**: A mock tool that drafts and schedules social media posts based on inventory status.

### `send_slack_approval(draft_copy, sku)`
- **Purpose:** Acts as a Human-in-the-Loop safety checkpoint. Routes the generated copy to a mock Slack channel and pauses the agent's execution.
- **Inputs:** 
  - `draft_copy` (string): The promotional text generated by the agent.
  - `sku` (string): The product identifier.
- **Returns:** A string observation indicating either "Status Approved" or "Status Rejected" based on human terminal input.
